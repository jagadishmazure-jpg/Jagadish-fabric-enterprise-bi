# Documentation

Start with [architecture.md](architecture.md) for the whole picture and
[implementation-guide.md](implementation-guide.md) to run it. Each component guide follows the
same structure: purpose, architecture, how it works, key files, code excerpts, configuration,
how to run it locally with real output, tests and eval gates, guardrails and security,
observability, failure modes, the mapping to the real Fabric or Azure service, and limitations.
