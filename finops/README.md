# `finops`

Inputs for the capacity estimate. `scripts/cost_report.py` turns them into [docs/cost-estimate.md](../docs/cost-estimate.md). All figures are estimates.

| File | What it does |
|---|---|
| [`README.md`](README.md) | This file |
| [`workloads.yaml`](workloads.yaml) | Per-workload CU assumptions, list prices used, and scale factors |

Run: `python -m fabricbi.examples finops`. Guide: [finops.md](../docs/finops.md).
